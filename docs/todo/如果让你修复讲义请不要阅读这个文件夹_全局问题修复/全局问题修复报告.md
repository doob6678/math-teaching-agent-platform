# 全局问题修复与收敛报告

更新时间：2026-08-04

## 一、收敛结论

原始审计中的权限、租户隔离、后台误启动、迁移漂移、上传资源耗尽、请求主体伪造、AI 取消/并发和虚假健康检查问题已完成第一轮根因修复。问题列表不再按原始文件逐项重复，而按以下边界管理：

- 已关闭：运行时 capability token 协议、客户端租户注册、资源越权、消费者绕过开关、Feishu 空资源全量扫描、ZIP 资源耗尽、客户端 IP/设备信任、SSE 取消、模型共享并发、虚假健康状态。
- 明确排除：`localPath` 路径收敛。该字段是本地开发/本地使用能力，按要求保留，不作为产品缺陷继续修复。
- 仍需后续治理：HTTPS Cookie 部署开关、查询和检索扩展性、上传临时文件生命周期、两套讲义链路和大类拆分、协议契约一致性、工作区整理。

## 二、已完成的关键修复

### 1. 身份、权限和限流

- 删除 capability token 的运行时服务、校验器、审计 API、DTO、实体、存储和测试代码。
- 请求身份统一由后端 Sa-Token 会话或受注册的 MCP 服务主体解析；不再接受客户端 `X-Subject-*`、请求 Hash 或 capability header 作为授权依据。
- 注册接口不再信任客户端 `tenantId`，使用后端配置的默认注册租户。
- 教师资源、题库、学生记忆、学习快照和 Agent 执行重新按租户、角色、主体 ID、所有者和共享范围判断。
- `MATH_VIP`、`TENANT_PUBLIC`、`PUBLIC_TEXTBOOK`、`CLASS_AUTHORIZED`：同租户学生可读；`TEACHER_PRIVATE`：仅资源所有者或管理员可读；教师上传未指定范围时默认 `TENANT_PUBLIC`。
- 限流按后端解析的用户主体聚合；策略中的 `0` 不再表示无限制，而是落到按访问级别配置的安全默认桶。匿名请求只使用匿名主体兜底。
- 不信任 `X-Forwarded-For` 和 `X-Device-Id` 作为认证或限流主体。

## 三、仍需保留的问题列表

以下项目没有被本轮伪装成“已解决”，它们是当前收敛后的真实待治理项：

### P1：部署安全策略

1. Cookie 的 `Secure` 由环境变量控制，适配本地 HTTP 开发；真实 HTTPS 部署必须显式开启 `MATH_AGENT_AUTH_COOKIE_SECURE=true`。

### P1：资源生命周期和数据规模

2. 普通上传归档后的长期保留策略仍需统一生命周期清理、失败保留窗口和磁盘阈值告警。
3. 题库、学生记忆和部分检索链路仍有“候选加载后再 limit/排序”的扩展性风险，需要继续下推 SQL Top-N、增加索引或采用分层召回。
4. 教材 BM25 内存语料、Milvus `FLAT` 索引和默认缓存策略在语料持续增长后会成为延迟和内存瓶颈，需要持久化倒排索引、ANN 索引、分区和有上限缓存。

### P1：功能契约和架构治理

5. `MultiAgentWritingService` 与 `TeachingWorkflowService` 仍是两套讲义执行链路，状态机、导出和错误处理存在长期分叉风险。
6. 教学工作流、MCP graph spine、工具发现和多 Agent trace 仍需继续做协议契约验收，尤其要固定阶段顺序、状态转换和空结果语义。
7. `TeachingWorkflowService`、`TeachingWorkflowExecutionSupport`、`MultiAgentWritingService`、`App.tsx`、`textbookApi.ts` 仍然偏大，需要按权限、状态、调度、导出、持久化和 UI/API client 拆分。

### P2：工作区治理

8. 当前工作区仍有其他开发者并行产生的大量未提交修改、未跟踪文件和 `NUL`。本轮没有 reset、checkout、clean 或删除它们；脏工作区是协作状态，不是产品运行时缺陷。需要项目负责人按提交边界整理后才能做可靠合并。

## 五、最终边界

- Capability token 不再是当前运行时认证、授权、审计或限流机制；当前机制是后端用户/服务主体 + 租户 + 角色 + 所有权 + 共享范围。
- `MATH_VIP` 只是资源共享权限域名称，不是 token，也不是登录凭证；同租户学生按共享资源规则读取，写入和管理仍受角色与所有权约束。
- `localPath` 按本地开发要求保留。
- 当前未收敛项已经从原始审计的逐文件问题收敛为 8 个可执行治理项，主要集中在 HTTPS 部署安全、数据规模、双链路架构、协议契约和工作区治理。
