# 目录驱动知识点讲义设计

## 目标

一份讲义对应一个目录小节。后端先从已同步资料中确定该小节的具体知识点，再针对每个知识点检索教师资料与题库，形成内容充足、题目真实、图片可显示的教师版、学生版和 16:10 讲解版。

## 内容结构

讲义不再输出固定的“核心方法”“解题步骤”标题。标题层级是：讲次标题、`本节目标`、一个或多个具名知识点。每个知识点包含：必要定义/结论、命中的真实例题、带依据的解析、一个同知识点变式练习；有可用资料图片时紧跟对应题目或结论。标题必须由知识点真实名称组成，禁止编号占位标题、流程话术和提示词。

## 生成链

1. 用用户选择的目录小节作为检索锚点；教材命中提供章节和知识点候选。
2. 为每个候选知识点分别查询已授权的教师资料 RAG；将命中的资料块和图片资产绑定到该知识点。
3. 对每个知识点分别查询知识点题库，拒绝 OCR 拼接、多题包和主题不匹配题目；至少保留一题作为例题，另取一题作为变式。
4. AI 只接收结构化、压缩后的知识点包，按知识点生成讲解文字；AI 配置以任务请求中的受限模型选项传递，前端不显示提示词、内部模型参数或调试信息。
5. 版式生成器按知识点循环输出。教师版保留解析，学生版保留例题题干、提示与足够空白，讲解版每个知识点一张或多张独立横页。

## 资源与安全

图片只使用后端已经同步、当前用户有权限读取的教师资料资产或本地教材页图；无法读取的 URL 不进入 PDF。资料证据仍在任务审计区可点开查看，正文只呈现题目需要的图，不粘贴来源/OCR 块。

## 验收

- 真实目录小节任务至少识别两个具名知识点。
- 每个知识点在教师版均有一题真实例题和一个变式练习；题目内容与知识点匹配。
- PDF 不出现“核心方法”“解题步骤”“题目入口”、模板/提示词/benchmark 等文字。
- 已授权图片可写入 PDF；失效图片不显示失效链接或占位符。
- AI 自定义选择校验角色权限、配置是否启用和模型目录，未授权值回退到默认配置。
