# 数学讲义平台 · 安卓客户端 UI 设计任务书 v3（2026-09-01）

> v1 定义拍照上传工具；v2 升级为网页端大部分功能的手机伴侣客户端；**v3 新增第七节"高级交互规格"（上传进度/图片预览/资料上传/搜索/对话恢复）与第八节"客户端技术约束"**，并补齐对应交付物。

## 一、产品定位

一句话：**把讲台上和路上的时间还给老师/学生**——网页端是完整工作台，手机 App 是随身客户端：随时问 AI 讲题、发起讲义生成、拍题入库、查看进度与订正。

- 目标平台：Android 12+（API 31+），Material 3，竖屏单手优先，需适配平板/折叠屏。
- 与网页端共用同一套后端账号体系（登录一次，全端同步）。
- 设计灵魂：**离线不丢、加载不卡、流式不闪、退出可续**。

## 二、风格基调（与网页端同源）

- 关键词：**轻、干净、留白、克制**，直接对标 DeepSeek App 与我们网页端现状（Qwen 风格对话改版后的样子），设计师请先浏览网页端取齐气质。
- 主色 **#4D6BFE**，只用于主按钮、选中态、进度、品牌点，屏幕面积 ≤5%。近黑正文 #1A1A1F、三级灰；深色模式成套出稿（#0F0F13 底）。
- 明确禁止：蓝色聚焦描边高亮、渐变花哨背景、emoji 风图标、拟物。图标 Lucide/Material Symbols 线性风格。
- 数学公式是内容主角：所有含公式界面按 LaTeX 渲染区设计，设计稿用真实公式截图示意，不许用假字符糊弄。

## 三、功能移植映射表（网页端 → 手机端）

| 网页端功能 | 手机端范围 | 说明 |
|---|---|---|
| AI 讲题（流式对话） | **完整** | 核心页。流式回答、模型切换下拉、思考过程折叠、追问、历史、**退出恢复（见 7.5）** |
| 讲义生成工作台 | **完整（任务制）** | 提交目标→多 Agent 写作进度→教师/学生/课堂三版预览→PDF 下载分享 |
| 知识库 · 教材检索 | **完整（只读）** | 检索教材、看命中片段与页码定位（搜索体验见 7.4） |
| 知识库 · 高考压轴题库 | **完整（只读）** | 题目列表、详情、题图大图查看（预览器见 7.2） |
| 知识库 · 教师资料 + 拍照/资料上传 | **完整** | 照片网格、四态状态点、上传队列（进度规格见 7.1/7.3） |
| 学生视图（订正/速记/变式） | **完整** | 学生账号可见；教师账号此位变"我的学生" |
| AI 控制台 / Agent Trace 明细 | **简化只读** | 只留任务运行状态卡片，明细日志不上手机 |
| MCP 接入、密钥管理 | **不移植** | "我的"里留一行"请到网页端管理" |
| 系统设置 | **精简** | 深色模式、字号、图片质量/蜂窝上传、缓存清理、退出登录 |
| 模板货架、同步检查点 | **不移植** | 保留网页端 |

判断标准：设计师对任何一格觉得"手机上做不动/体验差"，标注出来，我们砍，不硬塞。

## 四、信息架构

底部导航 4 项 + 全局中央拍照键：**对话 · 讲义 · (⊕拍照) · 知识库 · 我的**。

- 中央 56dp 主色 FAB 唤起取景器，v1 拍照流保留（极简取景、连拍、缩略图飞入、后台队列、离线状态点、恢复网络补传提示）。
- 拍完默认进"教师资料"，取景器顶部一次性选择"作为讲义配图 / 作为错题"。

## 五、关键页面设计要点

**1. 对话（AI 讲题）**：顶部会话标题+模型切换胶囊（自定义下拉，非系统 Spinner）；用户消息浅主色底、AI 消息纯白；输入栏带拍照/相册附件。流式体验是验收核心：逐 token 打字机、2dp 主色细光标；"思考中"可折叠浅灰思考区，回答开始后收成"已深度思考 · 12s"一行；生成中底部"停止生成"胶囊；首字 <5s，等待期三点呼吸占位，不许全屏菊花。消息内公式块、例题卡分节变纵向手风琴。消息状态机与恢复交互见 7.5。

**2. 讲义**：列表=任务卡片流（PDF 首页缩略+状态徽标：排队/写作中·进度%/待审阅/完成/失败）。新建页一个大输入框+结构化字段折叠区。多 Agent 写作进度是招牌动效：资源策展→规划→写作→审阅流水线，当前段主色呼吸、完成段打勾、节点间光点流动；可退出，回来状态不丢。预览页三 Tab（教师/学生/课堂版），学生版顶部常驻浅绿提示"此版本无答案"。

**3. 知识库**：顶部分段控件三分区。教材检索=搜索框+结果卡（片段、完整来源名、页码徽章）→只读原文视图（图片页+文字对照）；高考题库=题列表+详情大图；教师资料=照片网格+状态点+队列面板+多选条。

**4. 我的**：头像+角色徽标、存储/流量两行、缓存占用与"清理"入口、精简设置、"网页端管理"提示行；学生在此看订正记录。

## 六、加载与动画规格（基线）

- 骨架屏（仅首次访问显示）、crossfade 200ms、共享元素大图 300ms、spring 下拉刷新——同 v1 第六节。
- 流式文本：新行 translateY 8dp+淡入 100ms；禁止整段重排跳动（打字机宽度预占位）。
- 任务状态变化：徽标色彩过渡 250ms+完成轻震动；流水线光点 ≤12fps 省电。
- Tab 切换淡入 150ms 不做横向滑动；FAB↔取景器容器变换 400ms。
- 全部动画遵循系统"移除动画"开关，备注降级方案。

## 七、高级交互规格（v3 新增，本次设计重点）

### 7.1 图片上传：进度体系

- **格内进度环**：网格每格右下角状态点升级为 2dp 主色圆弧（与 v1 状态点同位同尺寸，未上传=空心灰、上传中=圆弧+百分比仅长按浮出、完成=绿勾、失败=橙叹号）。**不做每格独立大进度条**——满屏进度条是灾难。
- **全局进度胶囊**：有任务进行时，顶栏下方常驻一条 32dp 胶囊"上传中 3/12 · 45%"，点击展开队列面板；无任务 300ms 淡出。
- **断点续传语义**：网络中断进度**冻结不回零**，恢复后从断点继续，胶囊文案变"续传中"。
- **队列面板**：按时间分组；失败项右滑展开原因（网络/过大/格式）；"全部重试"按指数退避自动进行，手动重试置顶。
- 压缩策略透明化：默认"智能压缩"（1080p、q80），"我的"里可切"上传原图"；拍照确认页显示预计大小。

### 7.2 图片展示与预览器

- **三级加载，旧的必须秒开**：内存缓存（0 帧）→本地磁盘缓存（≤100ms，直接显示，无骨架屏）→网络（骨架屏+crossfade）。**凡是看过的图，重进 App、翻旧对话、回老资料，一律不许出现二次加载闪烁**——这是本次验收硬指标。
- **大图查看器**（对话/题库/教师资料通用组件）：双指缩放、双击缩放到指尖位置 2.5x、横滑翻页（页码"3/12"极小字）、下拉跟手关闭（松手回弹或关闭）、长按浮出保存/分享/设为讲义配图。
- 查看器是唯一允许横屏的界面；深色沉浸底 #000，工具栏 3 秒自动隐藏。

### 7.3 资料上传（非照片：PDF/Word/多图混合）

- 入口：教师资料页"＋"→ 系统文件选择器 / 相册多选；一次提交算一张"资料卡"（首页缩略+页数/大小/类型徽标）。
- **三段迷你流水线**（复用讲义流水线视觉语言，缩到 24dp 高）：上传% → 解析中（逐页缩略图点亮）→ 入库检索就绪（绿勾）。任何一段失败给出单段重试。
- 解析中资料卡可点开看已解析页（渐进可用），不许整卡置灰等待。

### 7.4 搜索内容

- 搜索页三层结果：**本地缓存结果立即显示**（右上"来自缓存"灰标）→ 网络结果到达后 DiffUtil 原位替换/追加（新增项主色描边一闪 800ms），全程不跳页面骨架。
- 输入防抖 300ms；历史词 chips（可单删/清空）；结果内关键词主色加粗高亮；命中教材片段点击深链到**原页码定位**（原文视图自动滚到该页）。
- 空结果：给"换个说法"建议 chips（AI 生成），不留死胡同。

### 7.5 对话不丢失与退出恢复（v3 核心）

**消息状态机（设计稿每种状态都要出）**：
`待发送(离线灰) → 发送中 → 流式输出中 → 已完成 / 失败(可重试) / 已中断(可继续)`

- **流式落盘检查点**：AI 回答每完成一个段落（或每 256 token）持久化一次；App 退后台、被系统杀进程，本地已生成的部分**永远还在**。
- **场景 A · 退后台再回来**（最常见）：先 0ms 渲染本地已存内容（光标停在断点，下方三点呼吸），同时静默重连服务端流，从检查点继续打字机输出——用户感知是"它一直在写"。若期间服务端已写完，直接补全整段+完成徽标，无跳变。
- **场景 B · 进程被杀重进**：进对话页即从本地库加载历史消息（秒开），最后一条流式消息显示"已中断 · 继续生成"胶囊，点击续写；不点则保留原文可复制。
- **发送失败**：用户消息变"待重发"灰态+重试图标，重发成功自动转正常气泡；离线可编辑可入队，联网自动发出。
- 恢复失败兜底：顶部细条"内容恢复失败，点击重试"，**已显示内容永不清空**。
- 历史会话列表：每条显示最后消息摘要+未读生成完成小红点；本地缓存最近 50 会话全文，更早的按需拉取（列表项先显示占位摘要，点开再加载正文）。

## 八、客户端技术约束（给设计师理解，开发侧照此实现）

设计稿不得违反以下约束，否则打回：

1. **单一数据源**：所有进度/流式文本来自后台线程合并到一条状态流，UI 每帧只读快照——所以**不要设计**需要多源实时同步的花活（如双进度条互相追赶）。
2. **后台任务一律 WorkManager 语义**：可被系统杀死、重启后自动续跑。禁止设计"必须保持前台/亮屏才能完成"的流程；所有长任务（上传、解析、讲义生成）都要有"杀掉也没关系"的恢复态（对应 7.5 场景 B 的通用化）。
3. **重活不进主线程**：图片压缩、哈希、DB 写入、公式排版全在后台；UI 动画只用 GPU 层属性（位移/缩放/透明度），每帧预算 16ms——标注动效时避免逐帧路径动画。
4. **列表并发更新安全**：一律 DiffUtil 增量刷新，新消息/新照片**原位插入不整屏重排**；设计时假定同一秒内可能同时到达：上传进度×N + 流式 token + 搜索结果替换。
5. **存储配额**：Room 会话/任务库 + Coil 磁盘 LRU 256MB（"我的"里可见可清）；设计需含"存储不足"提示态（上传与缓存写入前检查）。
6. **分页**：所有列表 30 条/页无限滚动，禁止设计"一次加载全部"的长截图式页面。

## 九、适配规范

- 断点：360dp（基准稿）/ 411dp / ≥600dp 平板与折叠屏。≥600dp 时对话与讲义预览双栏（列表+详情并排），知识库网格 4 列。
- 字体缩放支持系统 200% 不破版，标注哪些文本折行哪些截断。
- 刘海/手势条安全区；横屏只允许出现在大图查看器。
- 长数学公式横向滚动容器组件规范（含滚动渐隐提示）。
- 弱网/离线全链路：对话"待重发"、讲义只读缓存版、上传冻结——每个受影响界面都要画离线态。

3. 动效演示八段：流式打字、**后台返回续流（7.5 场景 A）**、中断续写胶囊、思考区折叠、流水线光点、FAB→取景器、网格→大图、骨架→图片，标注时长/曲线。
4. "设计原则+移植映射表+技术约束摘要"封面页，禁则单列。
5. 全部界面按 加载/空/失败/离线/正常 五态补齐；对话页额外补"恢复"两场景。
