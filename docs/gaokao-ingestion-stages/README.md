# 高考真题入库阶段目录

本目录是本轮计划的持久进度面板。每一阶段都记录完成条件、证据、发现与未满足的外部前置条件；状态不会把“已设计”写成“已验收”。

## 已验证的页图成本发现

真实北京卷第 1 页对照证明，整页初筛不应发送原始 PNG：原图的 prompt 为 3,130 token；960px、JPEG quality 0.82 派生图为 949 token，降低 69.7%，且仍返回题号 1–7、单栏和第 7 题跨页风险。继续压到 768px、quality 0.78 后，模型错误丢失跨页风险，故该档位禁止使用。

生产链路现在为每一页保留原始 PNG，并生成同目录的 `page-N-initial-review.jpg`；只有后者可供低成本页面初筛。几何图、公式、跨页与低置信度题必须使用原页 PNG 或高清单题裁图。参数写在 `application.yml` 和 `config/gaokao-ingestion-2024.json`，不依赖本地目录环境变量。完整实验见阶段 13。
