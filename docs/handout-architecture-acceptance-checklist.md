# 讲义架构验收清单

本清单用于每一次教师版、学生版、课堂讲解版或其 PDF 的真实交付验收。未执行的项目保持未勾选；不得因已有历史产物、旧报告、旧截图或旧 PDF 将本次运行标记为通过。

## 本次运行记录

- [ ] 记录本次运行标识、执行时间和验收人。
- [ ] 记录本次来源证据位置、完整来源文件名和来源 SHA-256。
- [ ] 确认记录对应本次运行输入，不是历史 `output`、缓存或先前发布物。

## 内容与隔离

- [ ] 审阅调用链：可见教师、学生、课堂讲解正文仅由 AI/Python Writer 产生。
- [ ] 审阅 Java/前端变更：不存在固定教学文案、题目/主题分支、默认标题、答案、提示或自动生成的图像内容。
- [ ] 抽检学生版：没有最终答案、教师批注、推理轨迹或内部来源标识。
- [ ] 确认 RAG 后的 AI 仅读取或检索本次运行已授权文档，未提供任意文件系统或 shell 访问。

## 图片与来源

- [ ] 图片引用只包含不透明 `evidenceRef` 与 `assetId`；没有文件路径、URL、Base64 或 LaTeX 图片代码进入领域数据。
- [ ] 每张展示图片均能映射到本次运行授权的真实来源资产；无有效选择的区块不显示图片。
- [ ] 高中来源链路可复核 GPU PaddleOCR/版面资产、同源 Terra/Luna 页级转写、完整来源名目录、全文 Markdown、逐题 Markdown 和复制的来源资产。
- [ ] 在授权分块和向量入库前完成上述来源目录与资产发布，且入库记录能回溯到来源证据。

## PDF 交付

- [ ] 检查中文字符、数学公式和学生作答留白；公式未出现乱码、截断或歧义写法。
- [ ] 审阅本次生成 PDF 的全部页面视觉结果，确认正文、图片、页眉页脚和分页无重叠、裁切或空白异常。
- [ ] 保存本次 PDF 的真实编译/渲染结果与必要审阅证据；历史 PDF 或截图不计入本项。
- [ ] 所有必填项均有本次证据后，才将交付状态标记为通过。
