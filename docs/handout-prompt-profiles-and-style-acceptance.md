# 讲义提示词档案与样式验收

## 核心教学协议

所有写作 Agent 固定遵循：题型识别 → 方法梳理 → 分步推理 → 总结回顾。推理从解题目标开始，匹配高中知识点，整理已知条件，说明方法选择，再给出可核验步骤。教师稿必须包含严谨解释、考点、易错点、迁移与互动；学生稿和投影稿绝不泄漏最终答案。

运行时唯一事实源为 `MultiAgentHandoutPromptProfiles`；本文件用于产品审查，避免维护第二套会漂移的提示词。

## 可切换档案与代表性回答

### `teacher_deep`

教师备课与讲评版：AI 主题 H1、教学目标、知识关系、题型识别、方法依据、带理由的完整推导、答案与评分点、板书顺序、考点、易错点、`<wait>`、变式和总结。

```markdown
# 解三角形中的向量与面积
## 题型识别：先找可计算的面积桥梁
点积给出 $\cos A$，面积公式需要 $\sin A$。因此先由
$\vec{AB}\cdot\vec{AC}=|AB||AC|\cos A$ 确定余弦，再由
$\sin^2A+\cos^2A=1$ 转换；取正根的理由是 $0<A<\pi$。
理解检查：若点积为负，角 $A$ 先能判断出什么？<wait>
```

### `student_blank`

学生空白讲义：AI 主题 H1、真实题目、必要公式、方法选择问题、分层提示、连续编号和干净留白；不含最终答案、完整推导、评分点或教师话术。

```markdown
# 解三角形中的向量与面积（课堂练习）
1. 已知 $\vec{AB}\cdot\vec{AC}=6$，$|AB|=3$，$|AC|=4$。
（1）由点积公式写出关于 $\cos A$ 的等式：________________
（2）选择可用于求面积的公式，并说明还缺少哪个量：________________
<wait>
```

### `single_question_16_10`

16:10 单题课堂引导：只围绕一道题，展示目标、知识匹配、已知条件、方法选择和空白检查点；使用 `<wait>` 停顿；不含最终答案或完整解答。

```markdown
# 一道题看懂“点积到面积”的转换
## 先确定目标
面积公式需要哪个三角函数？________________
## 再检查已知
点积条件直接给出了 $\sin A$ 还是 $\cos A$？________________
请把两者之间的恒等关系写在板书上。<wait>
```

## Agent 门禁与 PDF 样式

| 阶段 | 门禁 |
|---|---|
| 资料整理 | 只使用真实证据，补全知识点、先修、难度和考点。 |
| 教师写作 | 每一步说明理由，输出完整解答。 |
| 学生/16:10 写作 | 阻断最终答案、完整解析、评分点和教师信息。 |
| 三类审校 | 逐项核查来源、受众隔离、公式、题图连续与版式边界。 |
| PDF 导出 | AI H1 命名；页眉页脚为导出参数，不重新调用模型；学生/16:10 导出前再次做答案泄漏门禁。 |
