# 高中数学知识图谱主干 v0.1

来源类型：人工整理主干数据。
默认用途：前端知识图谱展示、知识点匹配候选、RAG 路由先验。
使用原则：教材给“章节知识点主干”，飞书给“题型方法和老师沉淀”；不要把 OCR 自动图谱里的 page、formula、topic 碎片直接作为默认展示节点。

## 1. 函数

### 1.1 函数概念与表示
- 知识点：定义域、值域、解析式、分段函数
- 题型方法：定义域求解、值域求解、换元法、分离常数法

### 1.2 函数性质
- 知识点：单调性、奇偶性、周期性、对称性、最值
- 题型方法：单调区间判断、奇偶性判定、函数图像变换、抽象函数性质

### 1.3 函数零点
- 知识点：零点存在性、方程根与函数图像
- 题型方法：数形结合、参数分类讨论、零点个数判断

## 2. 导数

### 2.1 导数基本功
- 知识点：导数定义、求导法则、切线方程
- 题型方法：导数计算、切线问题、切点设参

### 2.2 导数研究函数
- 知识点：单调性、极值、最值、凹凸性
- 题型方法：导数分步研究、端点效应、隐零点、主元变换

### 2.3 导数综合
- 知识点：恒成立、存在性、参数范围
- 题型方法：放缩、同构、双变量、函数值比较自变量大小

## 3. 三角函数与解三角形

### 3.1 三角函数基础
- 知识点：诱导公式、同角关系、图像性质
- 题型方法：化简求值、图像平移伸缩、周期最值

### 3.2 正弦定理与余弦定理
- 知识点：正弦定理、余弦定理、面积公式
- 题型方法：边角互化、三角形面积、解三角形综合

## 4. 平面向量

### 4.1 向量线性运算
- 知识点：向量加减、数乘、共线
- 题型方法：基底表示、坐标运算、向量投影

### 4.2 向量数量积
- 知识点：夹角、垂直、投影
- 题型方法：向量和角度、数量积建模、几何转向量

## 5. 空间向量与立体几何

### 5.1 空间几何基础
- 知识点：空间点线面、平行、垂直
- 题型方法：线面关系判定、面面关系判定、辅助线辅助面

### 5.2 空间向量
- 知识点：空间向量坐标、法向量、夹角、距离
- 题型方法：建系、法向量、线面角、二面角、点到面距离

## 6. 直线与圆

### 6.1 直线
- 知识点：斜率、直线方程、距离
- 题型方法：设线法、点到直线距离、对称问题

### 6.2 圆
- 知识点：圆的方程、直线与圆的位置关系
- 题型方法：几何法、代数判别式法、阿波罗尼斯圆、看到直角想到圆

## 7. 圆锥曲线

### 7.1 椭圆
- 知识点：定义、标准方程、焦点、离心率
- 题型方法：定义法、焦点三角形、离心率求解

### 7.2 双曲线
- 知识点：定义、渐近线、离心率
- 题型方法：渐近线建模、焦点关系、参数范围

### 7.3 抛物线
- 知识点：定义、焦点、准线
- 题型方法：焦半径、弦长、定点定值

## 8. 数列

### 8.1 等差等比数列
- 知识点：通项、前 n 项和、性质
- 题型方法：基本量法、Sn 与 an 关系、等差数列经典结论

### 8.2 数列求通项与求和
- 知识点：递推、累加、累乘、错位相减
- 题型方法：构造法、裂项相消、错位相减、分组求和

## 9. 概率统计

### 9.1 概率基础
- 知识点：古典概型、条件概率、全概率、贝叶斯公式
- 题型方法：分类讨论、树状图、条件概率公式

### 9.2 统计与随机变量
- 知识点：数据的数字特征、样本数据分析、分布列、数学期望、方差、正态分布
- 题型方法：期望线性可加性、分布列构造、概率统计大题模板

### 9.3 成对数据的统计分析
- 知识点：成对数据、相关关系、线性回归模型、独立性检验、卡方统计量、列联表
- 题型方法：散点图判断相关性、最小二乘估计、回归直线、卡方独立性检验、显著性水平与临界值

### 9.4 抽样与统计推断
- 知识点：随机抽样、分层抽样、系统抽样、样本频率分布、用样本估计总体
- 题型方法：抽样方案选择、频率分布表与直方图、样本均值与方差估计

## 10. 集合、常用逻辑与代数基础

### 10.1 集合与常用逻辑用语
- 知识点：集合表示、集合关系、交集并集补集、充分条件与必要条件、全称量词与存在量词
- 题型方法：集合运算、命题真假判断、充要条件判定

### 10.2 一元二次函数方程不等式
- 知识点：一元二次函数、方程根、不等式解集、基本不等式
- 题型方法：图像法、根的分布、参数范围、基本不等式求最值

### 10.3 指数函数、对数函数与幂函数
- 知识点：幂函数、指数函数、对数函数、反函数、指数方程与对数方程
- 题型方法：定义域值域、单调性、换底公式、方程不等式同解变形

## 11. 复数、计数原理与二项式

### 11.1 复数
- 知识点：复数概念、复数四则运算、复数的几何意义、共轭复数、复数模
- 题型方法：复数相等、复数运算、复平面几何表示

### 11.2 排列组合
- 知识点：分类加法、分步乘法、排列、组合
- 题型方法：捆绑法、插空法、隔板法、正难则反、特殊优先

### 11.3 二项式定理
- 知识点：通项公式、系数、二项式展开
- 题型方法：指定项求解、系数和、赋值法

## 核心关系边
- 函数基础 -> 导数研究函数
- 函数零点 -> 导数隐零点
- 三角函数基础 -> 解三角形
- 平面向量 -> 空间向量
- 直线与圆 -> 圆锥曲线
- 数列基础 -> 数列求和
- 排列组合 -> 概率统计
- 函数图像 -> 数形结合
- 导数单调性 -> 参数范围
- 空间向量 -> 立体几何角度距离

- 题型方法：50 个以内
- 关系边：20-40 条
